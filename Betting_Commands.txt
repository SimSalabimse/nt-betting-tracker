# Betting Commands (Updated 2026-07-06 - Clear Step-by-Step Workflows + Mandatory Edges Update)

## Core Rules (Always Active)
- Follow `robust_betting_protocol_v2.md`, `nt-betting-skills.md`, and `long_term_staking_plan.md` by the letter in full.
- Research Depth Rule is mandatory (min 8-12 sources, 12-15+ for high-variance bets). Shallow research is a violation.
- Update `sport_edges_and_filters.md` **additively and mandatorily** when patterns are found during post-settlement (no longer optional).
- All GitHub updates follow Successful Push Workflow with full verification.
- bet_log.csv and current_bankroll.md updates happen **at the very end** of odds analysis (after all research and decisions).

## Step-by-Step Workflow for Analyzing Odds Files (Mandatory Order)

1. **Stage 1**: Rough EV scan + strong filtering across all markets.
2. **Stage 2**: Targeted deep research on shortlist (minimum source requirements enforced).
3. Multi-perspective simulation (Value/Risk/Data Hunter/Contrarian).
4. betting-value-calculator + explicit R/R + tiered staking.
5. Diversification and min 10 NOK check.
6. **Only at the very end**: Update bet_log.csv (pending bets) and current_bankroll.md.
7. Verify all updates with tree + re-read before any user-facing output.

## Step-by-Step Workflow for Settlements (Mandatory Order)

1. Analyze results with tool proof (actual scores, conditions, explanations).
2. Identify what worked vs failed (especially losses) + clear variance sources.
3. Record structured deep dive in the round file.
4. **Mandatory**: If meaningful patterns exist, make additive update to `sport_edges_and_filters.md`.
5. Update bet_log.csv (Result + P_L_NOK only, no notes).
6. Update current_bankroll.md correctly (full archive + live method).
7. Update nt-learning-reviewer tracker if applicable.
8. Final clean summary only **after** all file updates are verified.

## Best Primary Command
"Run full analysis on the attached/current odds file using adaptive research mode. Enforce Research Depth Rule. Output only in clean standardized format with bets table. Execute nt-bet-log-manager and nt-bankroll-tracker **last**."

## After Settlements Command
"Here are the settlement results: [paste]. Trigger full post-settlement-learning-reviewer. Follow the mandatory settlement workflow above (analyze results first, update edges if patterns found, then bet_log + bankroll last). Show proof of all updates before summary."

## Stats Command
"Show current performance and bankroll status."
