# Betting Commands (Updated 2026-07-09 - Phase 1B Active + Norsk Tipping Combo Rules)

## Core Rules (Always Active)
- **Phase 1B is now active** (max 1 double per round on strong cases only, 12-20 NOK stakes).
- **Norsk Tipping Rule**: No two legs from the same match in any combo/double. This must be explicitly checked before recommending any double.
- Research Depth Rule is mandatory.
- Update `sport_edges_and_filters.md` mandatorily when patterns are found.
- bet_log.csv and current_bankroll.md updates happen **at the very end** of odds analysis.

## Step-by-Step Workflow for Analyzing Odds Files
1. Stage 1 rough scan + filtering
2. Stage 2 deep research (Research Depth Rule enforced)
3. Multi-perspective simulation
4. betting-value-calculator + staking (respect Phase 1B limits)
5. If recommending a double: explicitly verify legs are from **different matches**
6. bet_log.csv + current_bankroll.md updates **only at the very end**

## Step-by-Step Workflow for Settlements
1. Analyze results with tool proof
2. Identify patterns + variance sources
3. Record in round file
4. **Mandatory** additive update to `sport_edges_and_filters.md`
5. Update bet_log.csv (no notes)
6. Update current_bankroll.md
7. Final summary only after all updates verified

If recommending a double, explicitly confirm legs are from different matches. Follow mandatory workflow (research first, updates last). Output only in clean standardized format with bets table."

## Best Command for Settlements
