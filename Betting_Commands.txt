# Betting Commands (Updated 2026-07-09 - Phase 1B Target Volume + No Placeholder Output)

## Core Rules (Always Active)
- **Phase 1B is active**: Aim for **3–6 quality bets** per mixed file (not the bare minimum). Max 1 double allowed on strong cases only.
- **Norsk Tipping Rule**: No two legs from the same match in any combo/double. Must be explicitly verified.
- Research Depth Rule is mandatory.
- Never output placeholder, garbage, or example data in tables — all numbers must be real.
- bet_log.csv and current_bankroll.md updates happen **at the very end**.

## Step-by-Step Workflow for Analyzing Odds Files
1. Stage 1 rough scan + filtering
2. Stage 2 deep research (Research Depth Rule enforced)
3. Multi-perspective simulation
4. betting-value-calculator + staking (respect Phase 1B volume target)
5. If recommending a double: confirm legs from different matches
6. bet_log.csv + current_bankroll.md updates **only at the very end**

## Step-by-Step Workflow for Settlements
1. Analyze results with tool proof
2. Identify patterns + variance sources
3. Record in round file
4. **Mandatory** additive update to `sport_edges_and_filters.md`
5. Update bet_log.csv (no notes)
6. Update current_bankroll.md
7. Final summary only after all updates verified
